## About Chladni Vibration Plate Simulator

Chladni Vibration Plate Simulator is an interactive physics simulation that illustrates how vibrating surfaces can form recognizable geometric patterns. It models sand particles moving toward nodal lines, making standing-wave behavior visible through an animated Canvas API display.

The simulator is designed for learners, educators, and anyone interested in visual experiments involving Chladni figures. Horizontal and vertical vibration modes can be changed with sliders, while particle quantity and vibration speed can be adjusted during the simulation to compare different results.

## FAQ

### What does the simulator visualize?

It visualizes Chladni figures by simulating sand movement across a vibrating plate. Particles tend to gather around the modeled nodal lines.

### Can I change the pattern?

Yes. Use the horizontal and vertical mode sliders to generate different standing-wave configurations.

### Can the animation speed be changed?

Yes. The vibration speed control can be adjusted while the simulation is running.

### Can I control the number of particles?

Yes. The sand particle count can be changed in real time through the interface.

### Where are the settings stored?

Settings are controlled in the browser interface. The project profile does not specify persistent settings storage.

### The animation is slow. What should I try?

Reduce the sand particle count or lower the vibration speed, then test the visualization again. Performance can vary by browser and device.

### How do I get updates?
